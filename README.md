# landing-page
The landing-page project demonstrate a simple static webpage built with html and css representing the flex-box and box-model skills.

## Topics Covered
The topics reflected in this project are as follows:-
- html boilerplate
- how to use div
- how to apply external css
- style elements using css
- various css properties like padding, margin, font-style, font-weight, background-color, color etc.
- the css box-model(padding, margin, border, content)
- css flex-box

**The webpage is deployed on github, you can visit it by clicking on: [landing-page](https://swifty-amay.github.io/landing-page/)**
